# CookieCare — What We Need From You (Legal Authoring Form)

**Please copy this file once for each new review type** (for example: one for GDPR, one for SaaS contracts, one for California employment terms).

Fill it in normal English. You do **not** need to know coding.

---

## Why we ask for this

CookieCare only checks what **you** tell it to check.

If you do not write a rule here, the product will not invent it.
If you write clear rules, the report is clearer and safer.

Incomplete packs are fine — mark them as **draft**. The user will see a warning that coverage is not finished.

## Simple rules to remember

1. **If you don’t write it, CookieCare won’t check it.**  
2. Use the **same names** for the same ideas across reviews (don’t call one thing two different names).  
3. If the user asks a narrow question, tell us what to focus on (Part H).  
4. Put citations you want in the memo yourself — don’t leave that to the AI.  
5. Incomplete is OK — just mark it **draft**.
