# GDPR Article 28 DPA skill

## Scope
Data Processing Agreements under GDPR Article 28 — processor obligations, subprocessors, transfers, and audit rights.

## What good looks like
- Documented instructions-only processing, confidentiality commitments, subprocessor flow-down, breach notification assistance, and audit rights.

## Red flags
- Missing processor obligation to assist with data subject requests.
- Subprocessor changes without prior notice or objection rights.
- No transfer mechanism for international data flows.
