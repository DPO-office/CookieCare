# NDA skill

## Required facts
- **Governing law** must be known before finalising miscellaneous provisions. If missing, ask which governing law applies.

## Mandatory requirements
- **Confidential Information** must be defined.
- **Confidentiality obligations** (use, protection, non-disclosure) must be stated.
- **Term / survival** of confidentiality obligations should be stated.

## Section mapping hints
- Definitions → sec-definitions
- Obligations → sec-confidentiality
- Term → sec-term
