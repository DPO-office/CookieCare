# MSA skill

## Required facts
- **Governing law** must be known. If missing, ask which governing law applies to this MSA.

## Mandatory requirements
- **Services scope** must be described.
- **Limitation of liability** must be present.
- **Term and termination** must be addressed.

## Section mapping hints
- Services → sec-services
- Liability → sec-liability
- Term → sec-term
