# DPDP (India) Data Fiduciary / Data Processor overlay

## Coverage
Primary sources are the Digital Personal Data Protection Act, 2023 (No. 22 of 2023, assented 11 August 2023) and the Digital Personal Data Protection Rules, 2025 (G.S.R. 846(E), 13 November 2025). This pack covers the private Data Fiduciary / Data Processor contractual relationship — processor engagement basis, fiduciary accountability, security safeguards, breach intimation to the Board and Data Principals, erasure flow-down, data quality, grievance redressal, children's data, cross-border transfer, and additional Significant Data Fiduciary duties. It does not cover Data Protection Board of India adjudication/appeal procedure or Consent Manager registration mechanics, which are regulator/registration matters rather than contract clauses.

See `SKILL.md` for the authored rule, risk, and clause sections.
